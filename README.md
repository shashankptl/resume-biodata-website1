# Personal Resume and Bio-data Website

A responsive multi-page website built for a Web Technology assignment.

## Pages
- `index.html` — Home page
- `resume.html` — Resume
- `biodata.html` — Bio-data
- `contact.html` — Contact form with client-side validation

## Technologies
HTML5, CSS3, JavaScript, jQuery 3.7.1 and GitHub Pages (hosting).

## Run locally
Open `index.html` in a browser. An internet connection is needed to load the jQuery CDN.

## Personalize before submission
1. Replace `Your Name`, initials, email, phone, address and education placeholders.
2. Update skills, projects, marks, dates, languages and hobbies to match your actual details.
3. Add your own profile photograph if required (replace the initials avatar in `index.html` and `biodata.html`).
4. Test every navigation link and the contact form.

## Deploy free using GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `resume-biodata-website`.
2. Upload all files and folders from this project. Keep `index.html` in the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for the deployment to finish. GitHub will show the published website URL in the Pages section, usually `https://YOUR-USERNAME.github.io/resume-biodata-website/`.

The contact form is a front-end demonstration only. It validates fields in the browser and does not send messages to an email account or server.
