EcoDyePredict – Machine Learning-Based Prediction of Dye Removal from Wastewater Using Pumpkin Seed Husk

Problem Statement: Textile, printing and dyeing industries generate wastewater containing synthetic dyes, which can cause environmental pollution. Identifying effective dye-removal conditions through repeated laboratory experiments can be time-consuming and resource-intensive.

Project Description: Developing a machine learning-based prediction system to estimate dye-removal efficiency using pumpkin seed husk as a potential low-cost and sustainable adsorbent for wastewater treatment. The system considers parameters such as initial dye concentration, adsorbent dosage, contact time, solution pH and temperature.

Technologies Used: Python, Machine Learning, Data Preprocessing, Data Analysis and Data Visualization.

My Contribution: Contributed to understanding the wastewater treatment problem, studying adsorption parameters, dataset preparation, data analysis and predictive model development.

Domain: Machine Learning and Environmental Sustainability.
